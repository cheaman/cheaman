# 도면 규칙 가르치기 — 먼저 읽으세요

v0.1 · 2026-10-29 · 전무님 PC 로 옮기면 이 폴더째 번호 폴더 안에 두십시오 (예 : `C:\00-clude_dev\NN-…\`)

## 지금 무엇을 누르면 되나

1. `2_실행기\실행.bat` 더블클릭 → 검은 창이 서버를 켜고 브라우저가 열립니다 (처음 한 번 ezdxf 를 깝니다 · 인터넷 필요)
2. 화면 위 띠에 **DXF 도면 짝 · 질문지 답 · 캡처(Ctrl+V)** 를 넣습니다 → 프로그램이 숫자를 세고, 이 PC 에 클로드 코드가 있으면 바로 되짚기를 받아 옵니다
3. 가운데 띠에서 **○ · × · 고쳐서 ○** → 아래 띠 규칙 목록에 쌓입니다
4. 바닥 단추 **○ 받은 규칙 → 올리기** → 정답지 시험이 돌고 `4_결과\규칙글_13장.md` 가 써집니다

클로드 코드가 없는 PC 면 `_주고받기\봐주세요_NNN.md` 가 생깁니다. 클로드 대화창에서 「봐주세요 봐 줘」 라고 하시면 `파악한것_NNN.json` 이 오고 화면에 카드가 뜹니다.
