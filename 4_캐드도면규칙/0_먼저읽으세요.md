# 도면 규칙 가르치기 — 먼저 읽으세요

v0.2 · 2026-10-29 · 전무님 PC 로 옮기면 이 폴더째 번호 폴더 안에 두십시오 (예 : `C:\00-clude_dev\NN-…\`)

## 교육 계획대로 — 자료를 많이 넣는 것이 아니라 차례대로

화면 맨 위 띠가 **지금 단원 · 다음에 넣을 자료 · 끝 조건** 을 말합니다. 단원 0 바탕 → 1 치수선 → 2 지시선 → 3 EL · 기호 → 4 변경 · 틀 → 5 종합. 한 회 = 자료 2 ~ 3개 · 되짚기 8줄 안. 단원 끝 조건이 되면 「단원 끝 → 다음 단원」. 계획 전문은 `1_계획\교육계획.md`.

## 지금 무엇을 누르면 되나

1. `2_실행기\실행.bat` 더블클릭 → 검은 창이 서버를 켜고 브라우저가 열립니다 (처음 한 번 ezdxf 를 깝니다 · 인터넷 필요)
2. 화면 위 띠에 **DXF 도면 짝 · 질문지 답 · 캡처(Ctrl+V)** 를 넣습니다 → 지시 문구 없이 프로그램이 숫자를 세고, 이 PC 에 클로드 코드가 있으면 바로 되짚기를 받아 옵니다. 늘 같은 말(과업 이름 · 배율 · 틀)은 설정 「AI 에게 늘 붙이는 한 줄」 에 한 번만. 지금까지 ○ 받은 규칙은 자동으로 같이 보내 같은 종류 일은 같은 방식으로 봅니다
   · AI 가 받은 것과 답한 원문은 ② 띠 위 「AI 에게 보낸 것」 「AI 답 원문」 으로 같은 화면 작은 창에서 봅니다
3. 가운데 띠에서 **○ · × · 고쳐서 ○** → 아래 띠 규칙 목록에 쌓입니다
4. 바닥 단추 **○ 받은 규칙 → 올리기** → 정답지 시험이 돌고 `4_결과\규칙글_13장.md` 가 써집니다
5. 머리 띠 **기억 창고 → 「규칙 글을 스킬에 붙이기」** → 다음 대화부터 클로드가 저절로 읽습니다 (처음 한 번 설정에 `cad-drawing-work\SKILL.md` 경로)

클로드 코드가 없는 PC 면 `_주고받기\봐주세요_NNN.md` 가 생깁니다. 클로드 대화창에서 「봐주세요 봐 줘」 라고 하시면 `파악한것_NNN.json` 이 오고 화면에 카드가 뜹니다.

## 화면의 말

| 화면의 말 | 무슨 뜻인가 |
|---|---|
| 되짚기 | AI 가 이해한 것을 한 줄 · 네 줄(어디 · 무엇이 · 어떻게 · 안 건드림) · 어디서 왔나로 돌려 말한 것 |

| 못 알아들음 | AI 가 이해 못 한 것 · 다시 말해 달라는 것 |
| 적정 · 보완 필요 · 자료 미비 | 시험 판정 · 자료 미비 = 고친 판이 없어 못 본 것 |
