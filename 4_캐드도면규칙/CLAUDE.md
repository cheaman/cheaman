- 목적 · 원칙 · 지금 어디까지 : `인수인계.md` · 사람 안내 : `0_먼저읽으세요.md` · 계획 : `1_계획\`
- 코드를 고치면 `python 5_시험/시험_엔진.py` 와 `bash 5_시험/시험_화면.sh` 를 돌리고 맞음 수를 적는다 · 판 번호는 서버.py `판` 한 곳
- 3_자료 · 4_결과 · _주고받기 의 자료 파일은 전무님 것 — 시험은 복사본에서 (시험_화면.sh 가 그렇게 함)
- 「봐주세요 봐 줘」 → `_주고받기\봐주세요_NNN.md` 를 읽고 `파악한것_NNN.json` 에 JSON 만 (스킬 tool-ai-bridge 4장 · 답하는 모양은 봐주세요 끝)
