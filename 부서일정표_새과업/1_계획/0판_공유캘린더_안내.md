# 0판 — 코드 없이 오늘 시작하는 법 (구글 공유 캘린더 하나)

> 1판 앱을 설치하기 전이라도, 또는 설치하고 나서도 이 캘린더가 **자료의 집**입니다. 1판 setup 이 만든 캘린더가 있으면 그것을 쓰고, 없으면 ①부터.

## 전무님이 하는 것 (한 번 · 30분)
1. 구글 캘린더(PC) → 왼쪽 「다른 캘린더 ＋」 → **새 캘린더 만들기** → 이름 **구조부 일정** (1판을 깔았으면 이미 있음 — 건너뜀)
2. 그 캘린더 설정 → **특정 사용자 및 그룹과 공유** → 부서원 구글 주소를 하나씩 → 권한 **「일정 변경」** (올리기도 하게)
   - 구글 계정이 없는 부서원은 1판 화면(주소 하나)으로만 올림 → 그 사람에게는 **「iCal 비밀 주소」** 를 주어 보기만
3. 부서원에게 아래 안내 한 장을 카톡으로

## 부서원 안내 (카톡에 붙여 넣기)
```
[구조부 일정 캘린더 안내]
① 메일함의 「캘린더 추가」 를 한 번 누릅니다 (구글에서 온 메일)
② 폰 캘린더(삼성 · 구글) 설정 → 캘린더 목록에서 「구조부 일정」 을 켭니다
③ 출장 · 휴가는 이 캘린더에 종일 일정으로 올립니다. 제목은 이렇게 :
   [출장] 홍길동 · 대전      [휴가] 홍길동      [반차] 홍길동 (오후)      [외근] 홍길동 · 양촌 과도교
④ 호두에도 올리던 것은 당분간 양쪽 다 (2주) — 불편한 점은 전무님께 한 줄
```

## 2주 뒤 재는 것
- 캘린더에 올라온 건수 vs 호두 건수 (빠진 것이 있나)
- 제목 꼴을 지킨 비율 (안 지키면 1판 화면이 필요한 까닭)
- 부서원 한 줄 불편 → 1판 화면 · 2판에 반영

## 1판 화면과의 관계
- 1판 화면은 이 캘린더를 읽고 씁니다. 제목을 `[종류] 이름 · 어디` 꼴로 쓴 일정은 화면이 종류 · 이름을 알아봅니다
- 화면에서 올리면 제목이 저절로 그 꼴이 됩니다 — 그래서 결국 화면으로 가는 것이 편합니다
