# 4_폰앱 — 휴대폰 홈 화면 껍데기 (깃허브 Pages · 2판)

- `올릴것/` 을 공개 저장소(보기 `cheaman/jungbu-schedule`)에 올려 Pages 를 켜면 `https://cheaman.github.io/<이름>/` 이 껍데기 주소
  - **저장소를 새로 만드는 것은 공개 게시라 전무님께 여쭙고 한다** (스킬 phone-app-shell) · 깃 작성자는 cheaman · cheaman@users.noreply.github.com
- 올리기 전에 `올릴것/index.html` 의 `앱주소` 를 배포한 웹 앱 주소(열쇠 없이 `…/exec`)로 바꾼다
- 부서원에게 주는 QR = `https://cheaman.github.io/<이름>/#m=<공유 열쇠>` — `#` 뒤는 서버로 가지 않고 폰에만 저장됨
- 아이콘 = `아이콘.html` (자주색 타일 + 흰 달력 한 장 + 오늘 칸) → 4_폰앱 에서 `NODE_PATH=$(npm root -g) node 4_폰앱/아이콘_만들기.js` 로 다섯 크기 (37 디자인실에 「아이콘 하나」 정식 요청 전 임시)
- 시험 : 로컬 서버에서 `올릴것/?화면=<시험 화면 주소>` → 열쇠 없음(QR 안내) · `#m=…`(저장 · 덮개 걷힘) 둘 다 본다
