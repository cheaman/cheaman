# 설치하는 법 — 처음 한 번, 20분쯤

> PC에서 합니다. 끝나면 휴대폰에는 주소만 옮기면 됩니다.
> 이 폴더의 파일 셋을 붙여 넣습니다: `appsscript.json` · `Code.gs` · `Index.html`

## 1. 구글 시트 만들기

1. 브라우저 주소창에 `sheets.new` → 빈 시트가 열립니다
2. 왼쪽 위 「제목 없는 스프레드시트」를 눌러 **나만의 유튜브** 로 바꿉니다

## 2. 앱스 스크립트 열기

3. 시트 메뉴 **확장 프로그램 → Apps Script** → 새 탭에 편집기가 열립니다
4. 왼쪽 위 「제목 없는 프로젝트」를 눌러 **나만의 유튜브** 로 바꿉니다

## 3. 설정 파일 붙여 넣기 (유튜브 API 켜기 · 서울 시간 · 나만 보기)

5. 왼쪽 맨 아래 **⚙ 프로젝트 설정** → **「편집기에서 'appsscript.json' 매니페스트 파일 표시」** 에 체크
6. 왼쪽 **‹ › 편집기** 로 돌아와 파일 목록의 **appsscript.json** 을 엽니다
7. 안의 글을 **전부 지우고** 이 폴더의 `appsscript.json` 내용을 붙여 넣습니다

> 다른 길 : 왼쪽 「서비스 ＋」 → **YouTube Data API v3** → 추가. (이 길로 하면 시간대는 ⚙ 설정에서 「(GMT+09:00) 서울」로 따로 맞춥니다)

## 4. 코드 붙여 넣기

8. 파일 목록의 **Code.gs** 를 열어 **전부 지우고** 이 폴더의 `Code.gs` 내용을 붙여 넣습니다
9. 파일 목록 옆 **＋ → HTML** → 이름을 **Index** 로 (뒤에 .html 은 저절로 붙음) → 안의 글을 지우고 `Index.html` 내용을 붙여 넣습니다
10. **💾 저장** (또는 Ctrl+S)

## 5. 처음 설정 실행

11. 위쪽 ▶ 실행 옆 함수 고르는 칸에서 **setup** 을 고르고 **▶ 실행**
12. 「승인 필요」 창 → **권한 검토** → 내 구글 계정 고르기
13. 「Google에서 확인하지 않은 앱」이 나오면 **고급 → 나만의 유튜브(으)로 이동(안전하지 않음)** → **허용**
    - 내가 만든 스크립트를 내 계정에서 돌리는 것이라 이 창이 뜨는 것이 정상입니다
14. 아래 실행 로그에 **「처음 설정 끝 — 채널 ○개 확인 · 새 영상 ○개」** 가 나오면 성공
15. 시트로 돌아가면 탭 셋이 생겨 있습니다 — **채널목록 · 영상 · 설정**
    - 「채널목록」의 예시 채널 11개 중 **상태 칸에 「못 받음」** 이 있으면 그 줄은 지우거나 주소를 고칩니다

이제 **매시간 저절로** 새 영상을 모읍니다.

## 6. 웹 화면 열기

16. 편집기 오른쪽 위 **배포 → 새 배포**
17. 「유형 선택」 ⚙ → **웹 앱**
18. 설명: `처음` · 다음 사용자 인증 정보로 실행: **나** · 액세스 권한이 있는 사용자: **나만**
19. **배포** → **웹 앱 URL** 을 복사합니다 (`https://script.google.com/macros/s/…/exec`)
20. PC 브라우저에서 그 주소를 열고 **즐겨찾기** 에 넣습니다

## 7. 휴대폰 홈 화면에 아이콘 놓기

21. 주소를 휴대폰으로 보냅니다 (카카오톡 「나에게 보내기」 나 메일)
22. 휴대폰 브라우저에서 엽니다 — **PC와 같은 구글 계정으로 로그인**되어 있어야 합니다
    - **아이폰** : 사파리 → 아래 **공유(□↑)** → **홈 화면에 추가**
    - **안드로이드** : 크롬 → 오른쪽 위 **⋮** → **홈 화면에 추가**

## 쓰는 법

| 하고 싶은 것 | 어떻게 |
|---|---|
| 채널 더하기 | 화면 **＋ 채널** → 유튜브 앱에서 채널 → 공유 → 링크 복사 한 주소 붙여 넣기 · 또는 「채널목록」 시트에 한 줄 |
| 해외 채널 찾기 | 화면 **찾기** 탭 → 낱말 · 언어 · 나라 → **＋ 이 채널 담기** · 또는 클로드에게 「여행 해외 채널 찾아 줘」 |
| 카테고리 이름 바꾸기 · 늘리기 | 「채널목록」 **카테고리** 칸만 고치면 탭이 따라 바뀜 |
| 채널을 잠시 쉬게 | 「채널목록」 **켜기** 칸을 `아니오` |
| 숨긴 영상 되살리기 | 「영상」 시트에서 그 줄 **상태** 칸을 `새 영상` |
| 쇼츠도 보기 | 「설정」 **쇼츠 빼기** 를 `아니오` |
| 지금 바로 새 영상 받기 | 화면 오른쪽 위 **↻** |

## 막힐 때

| 보이는 것 | 할 일 |
|---|---|
| 「죄송합니다. 현재 파일을 열 수 없습니다」 | 브라우저에 구글 계정 여러 개가 로그인돼 있을 때 납니다 — 시크릿 창에서 한 계정으로만 열기 |
| 재생 창이 까맣거나 「오류 153」 | 그 영상은 **유튜브에서 열기** 단추로 보기 |
| 채널목록 상태 칸 「못 받음: 찾지 못함」 | 채널 주소를 다시 복사해 넣고 **채널 번호(자동)** 칸을 비우기 → 다음 시간에 다시 찾음 |
| 「오늘 유튜브 한도를 다 씀」 | 아무것도 안 해도 됩니다 — 내일 저절로 다시 받음 |
| 새 영상이 안 들어옴 | 편집기 왼쪽 **⏰ 트리거** 에 `collect` 가 있는지 보기 · 없으면 **setup** 다시 실행 |

## 코드를 바꾼 뒤 (클로드가 고쳐 줬을 때)

붙여 넣고 저장 → **배포 → 배포 관리 → ✏ 연필 → 버전: 새 버전 → 배포**
(새 배포를 만들지 않으면 **주소가 그대로**라 휴대폰 아이콘을 다시 놓지 않아도 됩니다)
