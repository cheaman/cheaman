# 나만의 유튜브 창 — 계획서

작성 2026-09-30 · 상태: **목업 확인 기다림** (아직 코드 없음)

## 1. 하고 싶은 것 (한 줄)

유튜브 추천에 끌려다니지 않고, **내가 고른 채널만 카테고리별로(AI · 여행 · 음식/레시피 …) 최신순으로** 모아 보는 화면.
국내뿐 아니라 **해외 채널**도 찾아 넣고, **PC와 휴대폰 어디서나** 연다.

## 2. 되나? — 됩니다

| 물음 | 답 |
|---|---|
| 내가 고른 채널의 새 영상만 모을 수 있나 | 됨. 유튜브 공식 API(YouTube Data API)로 채널별 최신 영상 목록을 받음. 채널 하나에 1점, 하루 무료 한도 10,000점이라 채널 50개를 매시간 돌려도 1,200점 |
| 유튜브 추천(알고리즘) 없이 볼 수 있나 | 됨. 화면에 나오는 것은 **내가 넣은 채널 목록 → 시간순** 뿐. 추천 칸이 없음 |
| 해외 채널을 찾을 수 있나 | 됨. 두 길 — ① 클로드에게 「여행 해외 채널 찾아 줘」 하고 골라 넣기 ② 화면의 「찾기」에서 언어·나라를 정해 검색 (API 검색은 **내 시청 기록과 무관**, 하루 100번쯤) |
| 휴대폰에서도 되나 | 됨. 인터넷 주소 하나로 열리는 화면 → 휴대폰 **홈 화면에 아이콘으로 추가** (안드로이드·아이폰 모두) |
| 돈이 드나 | 안 듦. 구글 계정 하나로 무료 범위 안 |

### 알아 둘 것 하나 — 「유튜브가 나를 학습하는 것」

- 이 화면에서 영상을 **유튜브 앱으로 열어 보면**, 로그인된 상태라 시청 기록이 남고 유튜브 추천에는 여전히 반영됩니다.
- 이 화면 **안에서 재생**(임베드 · youtube-nocookie)하면 기록이 훨씬 덜 남습니다.
- 완전히 끊고 싶으면 유튜브 설정 → **시청 기록 일시중지**. 어차피 추천은 이 화면에서 안 쓰니 손해가 없습니다.

## 3. 이미 있는 것 조사 — 굳이 만들 이유가 있나

| 이미 있는 것 | 되는 것 | 안 맞는 점 |
|---|---|---|
| 유튜브 「구독」 탭 | 구독 채널을 시간순으로 | **카테고리로 못 나눔**, 옆에 추천·쇼츠가 계속 끼어듦 |
| 유튜브 재생목록 | 영상 하나씩 모아 둠 | 새 영상이 저절로 안 들어옴 — 손으로 넣어야 |
| FreeTube (PC 프로그램) | 구독을 「프로필」로 묶어 카테고리처럼 봄, 추천 없음 | **PC 전용**, 휴대폰과 목록이 안 이어짐 |
| NewPipe · Tubular (안드로이드 앱) | 「채널 그룹」으로 카테고리별 새 영상 | **아이폰 안 됨**, PC와 목록 따로, 공식 앱이 아니라 유튜브 약관 밖 |
| RSS 읽기 앱 (Feedly 등) | 채널 RSS를 폴더로 묶음 | 2026년 2월 유튜브 RSS가 여러 날 끊김(404) — 믿기 어려움 |
| 브라우저 확장 Unhook | PC 유튜브에서 추천 칸 숨김 | PC 브라우저만, 카테고리 없음 |

**결론** — 「카테고리별 + PC·휴대폰 같은 목록 + 추천 없음 + 해외 찾기」를 한 번에 하는 것은 없음 → 만들 값 있음.
(만들기 전에 안드로이드 폰이면 NewPipe 채널 그룹을 하루 써 보는 것도 방법. 거기서 불편한 점이 곧 이 도구의 요구사항)

## 4. 만들 값 판정 (관문 넷)

| 관문 | 판정 |
|---|---|
| 1. 자주 하나 (연 12회 넘게) | 통과 — 거의 매일 |
| 2. 답이 하나인가 | 통과 — 「채널 목록 → 새 영상 모으기」는 매번 같은 결과. 단 **어떤 해외 채널이 좋은가**는 판단이라 클로드 대화로 (도구에 넣지 않음) |
| 3. 대화로 안 되는 이유 | 통과 — 클로드 없이 휴대폰에서 아무 때나 열어야 함 · 채널 목록과 본 영상 기록이 쌓여야 함 |
| 4. 6개월 뒤 혼자 고치나 | 조건부 통과 — 서버·열쇠(API 키) 없이 **구글 계정 안에서만** 돌게 짜야 함 (아래 5장) |

## 5. 어떻게 만드나 — 짜임새

### 추천안 : 구글 시트 + 구글 앱스 스크립트 (따로 설치 · 서버 · 열쇠 없음)

```
[구글 시트 「채널목록」] ── 내가(또는 클로드가) 채널을 한 줄씩 적음
        │  카테고리 | 채널 이름 | 채널 주소 | 나라/언어 | 메모
        ▼
[앱스 스크립트 · 매시간 저절로]  유튜브 공식 API로 채널마다 새 영상 받기
        │  (쇼츠 빼기 · 60초 이하 거름 — 켜고 끄기)
        ▼
[구글 시트 「영상」]  제목 · 채널 · 올린 날 · 길이 · 봤음/나중에/숨김
        ▼
[앱스 스크립트 웹 화면]  주소 하나 → PC 브라우저 / 휴대폰 홈 화면 아이콘
        카테고리 탭 · 최신순 · 봤음 표시 · 나중에 보기 · 찾기(해외)
```

- **내 구글 계정 안에서만 돈다** — 화면 주소는 「나만 보기」로 두어 남이 못 봄
- 유튜브 API는 앱스 스크립트에 들어 있는 「고급 서비스」를 켜기만 하면 됨 → 구글 클라우드에 따로 앱 등록·열쇠 발급 없음
- 채널 목록은 **휴대폰 구글 시트 앱에서도 고칠 수 있음**. 화면의 「채널 추가」 단추로 채널 주소만 붙여 넣어도 됨
- 이전에 만든 「구글 앱스 스크립트 다리」(22번 운동타이머) 방식과 같은 틀 → 새로 배울 것 없음

### 견준 다른 길 (고르지 않은 까닭)

| 길 | 안 고른 까닭 |
|---|---|
| 깃허브 페이지 + 자동 실행 | 무료로 쓰면 화면이 **공개**됨, 열쇠를 따로 보관해야 함 |
| 회사 PC에서 도는 프로그램 | PC가 꺼져 있으면 휴대폰에서 못 봄 |
| RSS만 쓰기 | 2026년 들어 자주 끊김 → 보조로만 (API가 막힐 때 대신) |

## 6. 화면 (목업)

`1_계획/화면목업.html` — 휴대폰 폭과 PC 폭 둘 다. **이 모양으로 가도 되는지 확인이 필요합니다.**

- 맨 위 카테고리 탭 : 전체 · AI · 여행 · 음식/레시피 · (나중에 보기) · 찾기
- 영상 카드 : 썸네일 · 제목 · 채널 · 나라 표시(🇺🇸 🇯🇵 …) · 올린 지 몇 시간 · 길이
- 카드 단추 셋 : **봤음** · **나중에** · **숨김** (이 채널 영상 그만 보기 아님 — 그 영상만)
- 「찾기」 탭 : 낱말 + 언어(영어·일본어·…) + 나라 → 결과에서 **「이 채널 담기」** 누르면 카테고리 골라 채널목록에 들어감

## 7. 차례와 예상 시간

| 단계 | 무엇 | 어디서 | 예상 |
|---|---|---|---|
| 0 | **채널 모으기** — 카테고리 확정, 카테고리마다 국내 5 + 해외 10쯤 후보를 클로드가 조사 → 골라 주시기 | 대화 | 30분 |
| 1 | **목업 확정** — 이 계획서와 화면목업을 보고 고칠 곳 말씀 | 대화 | 10분 |
| 2 | **관통 구현** — 시트 · 수집 스크립트 · 카테고리 화면 · 휴대폰 홈 아이콘까지 한 줄로 이어지게 | 클로드 코드 | 1~2시간 |
| 3 | **붙이기** — 봤음/나중에/숨김 · 쇼츠 빼기 · 찾기(해외) · 채널 추가 단추 | 클로드 코드 | 1~2시간 |

| 5 | **90일 재기** — 90일에 3번 넘게 썼나, 마지막으로 쓴 날이 30일 안인가 | 점검 | — |

## 8. 정하실 것

1. 카테고리 — AI · 여행 · 음식/레시피 말고 더 있나 (예: 건축·구조, 운동, 음악)
2. 쇼츠 — 뺄까, 따로 탭으로 둘까
3. 재생 — 화면 안에서 볼까(기록 덜 남음), 유튜브 앱으로 열까(자막·화질 편함) — 둘 다 단추로 둘 수도 있음
4. 휴대폰 — 안드로이드인가 아이폰인가 (홈 화면 추가 방법만 다름)
