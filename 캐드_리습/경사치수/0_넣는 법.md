# 경사치수 리습 v0.1 — 넣는 법 · 확인할 것

치수보조선 경사를 다른 치수에 그대로 옮긴다. 옮길 때 다시 펴지지 않게 연관도 끊을 수 있다.

| 파일 | 쓰임 |
|---|---|
| `경사치수.lsp` | **캐드에 넣을 것** (CP949 · CRLF) |
| `경사치수_읽기용_UTF8.lsp` | 같은 내용을 UTF-8 로 둔 것. 고칠 때 이것을 고치고 CP949 로 다시 저장 |

## 넣는 법

1. 캐드에서 `APPLOAD` → `경사치수.lsp` 고르기 → [로드]
2. 늘 쓰려면 같은 창의 **시작하기 묶음(Startup Suite)** 에 넣기

## 쓰는 법

1. `RR` (또는 `DIMOBLCOPY`)
2. 경사가 있는 치수를 하나 찍기
3. 같은 경사를 줄 치수들을 고르고 Enter
4. 「연관을 끊을까요?」 → Enter(예) 를 누르면 옮겨도 경사가 남는다
5. 잘못했으면 `U` 한 번

## 회사 PC 에서 확인할 것 (사본 도면에서)

이 리습은 클라우드에서 짰다. 확인한 것은 괄호 짝 · 함수 이름 겹침 없음 · CP949 저장뿐이다. **캐드에서는 아직 돌려 보지 않았다.**

| # | 해 볼 것 | 맞으면 |
|---|---|---|
| 1 | 수평 치수 3개(연관 있음)에 경사 60° 치수를 원본으로 RR | 세 치수가 모두 60° 로 꺾이고, 알림이 「경사 줌 : 3개」 |
| 2 | 1 에서 Y → 붙은 선을 MOVE | 경사가 남음 |
| 3 | 1 에서 N → 붙은 선을 MOVE | 다시 펴질 수 있음 (전에 겪으신 일) |
| 4 | U 한 번 | 경사 · 연관 모두 RR 전으로 돌아감 |
| 5 | 수직 치수 · 정렬 치수에도 RR | 원본과 같은 방향으로 꺾임 |
| 6 | 반지름 · 각도 치수 · 잠긴 층 치수를 섞어 고르기 | 그것들은 건너뛰고, 건너뛴 개수가 알림에 뜸 |
| 7 | 경사 없는 치수를 원본으로 찍기 | 「경사가 없습니다. 다시 찍으십시오」 |

## 마무리하는 쪽(PC 의 Claude)이 볼 것

- **RR 이 겹치는지** : 정품 `acad.pgp` 에 `RR, *RENDER` 가 있으면 RR 을 쳤을 때 렌더가 뜰 수 있다. 겹치면 다른 글쇠로 바꾸고 긴 이름은 그대로 둔다
- **경사 방향 읽는 법** : 원본 치수의 정의점 14(보조선 2 시작) → 10(치수선 위치)을 보조선 방향으로 보고, 두 점을 `DIMEDIT 경사` 에 넘긴다. 그래서 각도 단위 · ANGBASE 와 상관없다. 10 이 꺾인 보조선 끝에 놓이는지는 확인 1 · 5 로 본다
- **LT 에 있는지** : `DIMDISASSOCIATE` · `command-s`(멈춤 처리에서 씀)가 LT 2027 에서 도는지
- 고친 뒤에는 `경사치수_읽기용_UTF8.lsp` 를 고치고 CP949 · CRLF 로 다시 저장한다
