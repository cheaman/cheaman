# 문서 보기 앱 — 클로드가 먼저 읽는 것

- 목적 : 갤럭시에서 카톡 · 내 파일로 받은 PDF · TXT · DOCX · HWPX · HWP · DOC 를 광고 · 가입 · 결제 없이 보는 앱. 보기만 한다.
- 사용자 : 전채만 (코드를 읽지 않음). 화면 문구는 쉬운 우리말로.
- 짜임새 : 안드로이드 앱 껍데기(작게 · 「열기」 「공유」로 파일 받기 · 최근 목록) + 보기 화면(HTML · 자바스크립트 부품). **인터넷 권한을 넣지 않는다.**
- 만드는 곳 : 사용자 PC. 묶기는 안드로이드 스튜디오의 도구로, 넣기는 USB(개발자 도구) — `1_폰에 설치.bat` 한 번.
- 지금 상태와 다음 할 일 : `0_다음에 여기부터.md`
- 계획 : `1_읽을거리/작업계획.md` — 단계마다 「넘어가는 조건」을 지킨다. 화면은 목업 승인 뒤에 짠다.
- `3_시험/받은문서/` 는 회사 자료다. GitHub에 올리지 않는다.
- 코드를 고치면 사용자에게 「`1_폰에 설치.bat` 누르기」를 알려 준다.
