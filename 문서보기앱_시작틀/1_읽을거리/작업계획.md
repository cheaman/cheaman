# 문서 보기 앱 — 작업계획 (PC에서 만들어 갤럭시에 넣기)

갱신 2026-10-01 · 휴대폰 : 갤럭시(안드로이드) · 만드는 곳 : 내 PC + 클로드 코드

---

## 한눈에

```
 내 PC (C:\00-clude_dev\NN-…_문서보기\)              갤럭시
 ┌──────────────────────────────┐   USB 선   ┌──────────────────────┐
 │ 클로드 코드가 앱을 짠다        │ ─────────▶ │ 「문서 보기」 앱       │
 │ 안드로이드 스튜디오가 앱을 묶는다│ 1_폰에 설치 │ 카톡 → 다른 앱으로 열기 │
 │ PC 크롬에서 먼저 시험한다       │   .bat     │  → 「문서 보기」 고름   │
 └──────────────────────────────┘            └──────────────────────┘
          │ 백업만 (받은 문서는 안 올림)
          ▼
   GitHub 비공개 저장소
```

- **돈 · 가입 · 인증 없음.** PC 프로그램은 모두 무료, 플레이스토어 등록도 하지 않는다
- **인터넷을 안 쓰는 앱.** 문서가 휴대폰 밖으로 나가지 않는다
- **USB 선으로 넣는다.** 구글이 2027년부터 전 세계로 넓히는 「개발자 확인」 제도에서도 USB(개발자 도구) 설치는 빠진다고 구글이 밝혔다(2026-10 기준). 그래서 PC 방식이 오래 안전하다

## 앱이 할 일 · 안 할 일

| 할 일 | 안 할 일 |
|---|---|
| 카톡 · 내 파일 · 메일에서 「열기」 / 「공유」로 받은 문서 보기 | 문서 고치기 · 저장하기 |
| PDF · TXT · DOCX · HWPX · HWP · DOC | 엑셀 · PPT (나중에 필요하면 더함) |
| 최근에 연 문서 목록 | 회원가입 · 광고 · 인터넷 |
| 글자 크게 · 작게, 쪽 넘기기, 찾기 | 클라우드 저장 |

### 형식마다 기대치 (실물로 시험 전 짐작)

| 파일 | 기대 | 쓰는 부품 (모두 무료 공개) |
|---|---|---|
| PDF | 원본 그대로 | pdf.js (모질라) |
| TXT | 그대로 · 옛 한글(EUC-KR)도 안 깨짐 | 안드로이드 기본 + 글자판 자동 판별 |
| DOCX | 대체로 원본 비슷 · 쪽 나눔은 다를 수 있음 | docx-preview |
| HWPX | 글 · 표 · 그림 대체로 | 직접 읽음 (압축 안의 XML) |
| HWP | 글 · 표는 나옴 · 복잡한 편집은 어긋날 수 있음 | hwp.js 등 후보 견줘 고름 |
| DOC (옛 워드) | **글자 위주** | 글자만 뽑음 |

깨지는 문서를 위해 화면에 **「글자만 보기」** 단추를 둔다.

## 짜임새 — 왜 이렇게 하나

```
안드로이드 앱 (껍데기, 작음)
 ├─ 「열기 · 공유」 목록에 이름을 올린다
 ├─ 받은 파일을 보기 화면에 넘긴다
 └─ 최근 목록을 휴대폰 안에 적어 둔다
보기 화면 (HTML · 자바스크립트)
 └─ 형식마다 부품으로 그린다
```

- 보기 화면이 HTML이라 **PC 크롬에서 먼저 시험할 수 있다.** 폰에 넣기 전에 잘못을 잡는다
- 껍데기를 작게 두어야 6개월 뒤에 고칠 곳이 보기 화면 하나로 좁혀진다

## 준비 — 전무님 손으로 한 번 (약 1시간, 대부분 내려받는 시간)

### PC (모두 무료)

| | 무엇 | 어디서 | 메모 |
|---|---|---|---|
| ① | GitHub Desktop | desktop.github.com | 이미 있으면 건너뜀 |
| ② | 안드로이드 스튜디오 | developer.android.com/studio | 디스크 10~15GB. 처음 켤 때 「Standard」 고르고 끝까지 받기. 이후 창을 열 일은 거의 없음 |
| ③ | 삼성 USB 드라이버 | developer.samsung.com → Android USB Driver | PC가 갤럭시를 알아보게 함 |

### 갤럭시

| | 할 일 | 자리 |
|---|---|---|
| ① | 개발자 옵션 켜기 | 설정 → 휴대전화 정보 → 소프트웨어 정보 → 「빌드번호」를 7번 누름 |
| ② | USB 디버깅 켜기 | 설정 → 개발자 옵션 → USB 디버깅 |
| ③ | **자동 차단 끄기** | 설정 → 보안 및 개인정보 보호 → 자동 차단. 켜져 있으면 USB 설치가 막힌다. 앱을 넣은 뒤 다시 켜도 된다 (고친 판을 넣을 때만 잠시 끔) |
| ④ | 선 꽂고 허용 | 폰에 「USB 디버깅을 허용할까요?」 → 「이 컴퓨터에서 항상 허용」 |

## 단계 — 한 대화에 한 단계씩

시간은 클로드가 일하는 시간. 전무님 확인을 기다리는 시간은 뺐다.
Pro 5시간 한도를 생각해 **대화 하나에 한 단계**를 권한다.

| 단계 | 할 일 | 전무님이 하실 일 | 넘어가는 조건 | 예상 |
|---|---|---|---|---|
| **0** | 준비 확인 — `0_준비확인.bat` 을 만들어 PC 프로그램 셋과 폰 연결을 한 번에 검사 | 위 「준비」 · bat 누르기 | 검사 결과가 모두 「됨」 | 10~20분 |
| **1** | 화면 목업 — 최근 목록 · 보기 화면 · 글자 크게 · 「글자만 보기」 | 보고 **승인** | 승인 | 10~20분 |
| **2** | 관통 — 빈 앱 → `1_폰에 설치.bat` → 카톡 PDF가 열림 | 카톡 PDF 하나 열어 보기 | 카톡에서 「문서 보기」로 PDF가 열림 | 40~60분 |
| **3** | TXT · DOCX · HWPX 더하기 | 받은 문서로 열어 보기 | 셋 다 열림 | 30~50분 |
| **4** | HWP · DOC 더하기 — HWP 부품 후보를 실물로 견줘 고름 | 받은 문서로 열어 보기 | 둘 다 「열림」 (모양은 5단계에서 잼) | 40~70분 |
| **5** | 실물 시험 — `3_시험\받은문서\` 에 넣은 20개쯤을 PC에서 모두 열어 보고 표로 | 평소 받은 문서 20개 넣기 | 안 열리는 것 0 · 깨지는 것은 「글자만 보기」로 읽힘 | 30~40분 |
| **6** | 마무리 — 설치 안내 · GitHub 비공개 백업 · 도구목록과 런처에 한 줄 | 백업 「Publish」 한 번 | `0_다음에 여기부터.md` 가 최신 | 15~20분 |

**모두 합쳐 클로드 작업 3~5시간 · 대화 5~7번.**
2단계가 끝나면 그날부터 PDF는 쓸 수 있다. 다음 단계마다 고친 판을 `1_폰에 설치.bat` 한 번으로 덮어 넣는다.

## 폴더 모양 (처음부터 이대로)

```
NN-clude_dev_NN_문서보기\
├─ 0_다음에 여기부터.md      ★ 지금 어디까지 · 다음 할 일
├─ 1_폰에 설치.bat           (2단계에서 생김) 앱을 묶어 USB로 폰에 넣음
├─ 1_읽을거리\               작업계획(이 문서) · 의도와현황 · 화면목업
├─ 2_앱\                     안드로이드 앱 (껍데기 + 보기 화면)
├─ 3_시험\                   시험 대본 · 받은문서\ (GitHub에 안 올림)
├─ 4_설치파일\               만든 앱 파일(.apk) — 선 없이 넣을 때 씀
├─ _주고받기\넘길것.md
└─ CLAUDE.md                 루트라야 클로드가 읽음 — 옮기지 않음
```

- `3_시험\받은문서\` 는 회사 자료라 **GitHub에 올리지 않는다** (`.gitignore` 로 막아 둠)
- 선이 없을 때는 `4_설치파일\문서보기.apk` 를 구글 드라이브 등으로 폰에 옮겨 「내 파일」에서 눌러 넣는다. 처음 한 번 「이 출처 허용」이 뜬다

## 걸릴 수 있는 것 · 대비

| 걸림 | 대비 |
|---|---|
| HWP 모양이 깨짐 | 「글자만 보기」. 그래도 안 되면 HWPX로 받아 달라고 하는 게 가장 확실 |
| DOC(옛 워드)가 글자만 나옴 | 처음부터 그렇게 정함. 표가 꼭 필요하면 그때 다시 봄 |
| 카톡이 자기 미리보기로 열어 버림 | 카톡 파일 화면 오른쪽 위 「⋮ → 다른 앱으로 열기」 또는 「공유」. 첫 번에 「항상」을 고르면 다음부터 바로 |
| 수백 쪽 PDF가 느림 | 보이는 쪽만 그림 |
| 폰이 PC에 안 잡힘 | 0단계 `0_준비확인.bat` 이 무엇이 빠졌는지 한 줄로 알려 줌 (드라이버 · USB 디버깅 · 자동 차단 · 선이 충전 전용) |
| 2027 구글 개발자 확인 | USB 설치는 빠진다고 밝힘. 그때 다시 확인해 `0_다음에 여기부터.md` 에 적음 |

## 시작 차례 — 이 폴더를 PC로 가져가기

1. GitHub Desktop → File → Clone repository → `cheaman/cheaman` → 받을 자리는 아무 데나
2. 위쪽 「Current branch」 에서 `claude/mobile-document-viewer-app-qz06cl` 고르기
3. 그 안의 `문서보기앱_시작틀` 폴더를 통째로 복사해서
   `C:\00-clude_dev\NN-clude_dev_NN_문서보기\` 로 붙여 넣기 (NN은 도구목록의 다음 번호)
4. PC 클로드 코드에서 그 폴더를 열고 첫 마디:

```
NN번 폴더 시작합니다. 0_다음에 여기부터.md 를 읽고 0단계부터 같이 해 주세요.
```

(GitHub Desktop 없이 하려면 : github.com/cheaman/cheaman → 갈래 `claude/mobile-document-viewer-app-qz06cl` 고르기 → 「Code → Download ZIP」)
